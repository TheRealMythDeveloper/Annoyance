# WEB CHAOS 
## EPILEPSY WARNING

This script is a browser userscript that transforms ordinary webpages into visual chaos. It applies randomized visual distortions, layout changes, animations, typography effects, and glitch-inspired effects to make the web feel unstable.

## Features

- **Visual distortion**: Invert colors, grayscale, blur, hue shifts, oversaturation, and more.
- **Typography chaos**: Change fonts, spacing, text shadows, and text alignment.
- **Motion effects**: Shake, wobble, float, pulse, spin, and glitch elements.
- **Layout disruption**: Misalign elements, alter sizing, change spacing, tilt pages, and mirror content.
- **Screen effects**: Scanlines, flashes, outlines, and visual corruption.
- **Effect selection**: Enable or disable individual effects.
- **Presets**: Quickly load different chaos configurations.
- **Progressive corruption**: Gradually increase visual chaos over time.
- **Living chaos**: Periodically introduce additional visual disturbances.
- **Adjustable intensity**: Choose between multiple chaos levels.

## Installation

1. Install [Tampermonkey](https://www.tampermonkey.net/).
2. Download [the file](https://raw.githubusercontent.com/TheRealMythDeveloper/Annoyance/main/annoyance.user.js)
3. Save the script.
4. Visit a webpage and cause some chaos!

## Usage

1. Choose your chaos level.
2. Select a preset or customize your effects.
3. Open **FILTERS** to choose individual effects.
4. Turn on or off progessive or living chaos.
5. Click **INJECT CHAOS** to begin.


## Presets

- **Custom**: Manually selected effects.
- **Glitchcore**: Glitch-inspired visual effects.
- **Nightmare**: Distorted and unsettling presentation.
- **Broken Internet**: A chaotic, broken-web aesthetic.
- **Minimal Chaos**: A smaller selection of effects.
- **Everything Everywhere**: All effects enabled.

## Compatibility

WEB CHAOS is designed for websites running in a standard browser environment with userscript support. Some effects may behave differently depending on the website's layout, styling, or scripts.

## Disclaimer

WEB CHAOS changes the appearance and layout of webpages. Some effects may make pages difficult to read or navigate. Use it on pages you can safely reload.
